- Giao diện 2 bảng song song: bảng bên trái chứa văn bản đọc (tiếng Anh hoặc kịch bản gốc), bảng bên phải chứa bản dịch tiếng Việt để theo dõi nội dung.
- Dịch tự động từ bảng đọc sang tiếng Việt tức thì, không cần API key.
- Highlight nền vàng nhảy theo từng câu đọc và cuộn theo tiến trình theo thời gian thực (karaoke highlight đồng bộ cả 2 bảng).
- Chỉnh cao độ và tốc độ đọc, nghe thử trước khi xuất.
- Đọc kịch bản dài (hàng chục nghìn ký tự) cho video dài: tự chia đoạn, gửi song song, ghép thành một file mp3 duy nhất.
- Xuất kèm phụ đề `.srt` khớp thời gian (giữ chữ gốc, không theo từ điển), kéo thẳng vào CapCut hay Premiere.
- Mở file `.txt` và Word `.docx`.
- Từ điển cách đọc: `AI = ây ai`.
- Tự kiểm bản mới khi mở app, hỏi trước rồi mới cài: tải lỗi thì giữ nguyên bản cũ.

# Doc Voice (Text to Speech)

A Windows app that turns text into speech with Microsoft Edge Neural voices: 300+ voices in 70+ languages, including multilingual voices such as William and Andrew.

- Two-pane layout: left pane for source text to voice (e.g. English script), right pane for Vietnamese translation reference.
- Instant automatic translation to Vietnamese without requiring an API key.
- Real-time karaoke highlight: active sentence highlighted in yellow and auto-scrolled in sync.
- Adjust pitch and speed, preview before exporting.
- Long scripts (tens of thousands of characters) for long-form video: auto-chunked, parallel processed, and merged into one mp3.
- Exports a timed `.srt` subtitle file alongside the mp3 (original wording, not dictionary spellings).
- Opens `.txt` and Word `.docx` files.
- Pronunciation dictionary: `AI = ây ai`.
- Checks for new versions on launch and asks before installing: a failed download keeps the old version.

## Download

1. Get `DocVoice.exe` from [Releases](https://github.com/ducdg88/doc-voice/releases/latest).
2. Put it in its own writable folder (not Program Files) and double-click. No Python needed.
3. Output goes to `Documents\Doc Voice`: settings, dictionary and draft text live in `%APPDATA%\DocVoice`.

SmartScreen may warn because the exe is unsigned: click **More info**, then **Run anyway**.

Requires internet (voices are generated by Microsoft's service). For personal use: do not resell the voice service.
